# legal-evidence-os

Use this skill for litigation evidence work.

## Rules

- Separate facts, claims, inferences, risks, and next steps.
- Never invent dates, filings, legal authorities, quotations, or evidence.
- Preserve source integrity.
- Build source-backed matrices where possible.
- Flag missing records and contradictions.
- Use cautious legal language.

## Outputs

- chronology
- evidence matrix
- contradiction ledger
- issue/risk table
- missing-records checklist
- next-action plan
