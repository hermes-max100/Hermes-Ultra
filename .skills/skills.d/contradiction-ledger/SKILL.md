# contradiction-ledger

Use this skill to detect and catalog contradictions across evidence sources such as depositions, emails, declarations, and testimony.

## Rules

- Every contradiction must cite both sources with exact quotes.
- Rate severity as minor, moderate, or severe.
- Do not infer contradictions; only flag where text directly conflicts.
- Preserve full context around each conflicting statement.
- Note which source is more contemporaneous or more credible when the basis is explicit.

## Outputs

- contradiction ledger
- conflict pair table
- severity-rated issue list
- evidence cross-reference links
