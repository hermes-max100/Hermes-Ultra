# Virtual Creator Content Planner

## Purpose

Turn trend findings and persona memory into a concrete content calendar for an
AI-disclosed virtual creator. The planner drafts only; it never publishes.

## Inputs

- virtual creator profile JSON
- trend queue
- current offer
- prior analytics, if available
- target platforms
- calendar length, default 7 days

## Planning Mix

Use a 70/20/10 mix:

- 70 percent useful educational content
- 20 percent proof, process, or behind-the-scenes content
- 10 percent direct offer content

## Required Fields

For each calendar item include:

- date or day number
- platform
- format
- pillar
- hook
- content outline
- asset needs
- caption direction
- CTA
- AI disclosure note
- approval requirement

## Boundaries

- Do not publish or schedule live posts.
- Do not create fake personal availability or fake relationship claims.
- Do not include unsupported income, customer, or performance claims.
- Include an AI disclosure note for synthetic creator media.
- Human approval is required before posting, sending, deleting, or changing
  account settings.
