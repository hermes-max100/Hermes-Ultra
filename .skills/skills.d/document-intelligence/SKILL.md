# document-intelligence

Use this skill when documents need to be read, parsed, normalized, indexed, or converted into structured output.

## Rules

- Preserve original wording where legal or factual precision matters.
- Identify document type, date, author, recipient, source, and apparent purpose.
- Extract tables carefully.
- Flag unreadable, low-confidence, cropped, or ambiguous text.
- Do not infer missing text.

## Outputs

- extracted text
- document summary
- metadata table
- issue list
- structured JSON
- CSV-ready table
