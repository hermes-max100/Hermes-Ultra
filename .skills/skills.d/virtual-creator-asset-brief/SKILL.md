# Virtual Creator Asset Brief

## Purpose

Convert content calendar items into reusable media-generation briefs. The skill
creates prompts and production notes only; it does not upload or publish assets.

## Inputs

- persona profile
- content calendar item
- visual identity rules
- target format
- platform constraints

## Output

Return:

- asset title
- platform and aspect ratio
- scene description
- visual style
- text overlays
- negative prompts
- disclosure/watermark requirement
- QA checklist

## Hard Blocks

- No real-person likeness mimicry.
- No celebrity, influencer, private-person, or ex-partner lookalikes.
- No "make it indistinguishable from a real person" instruction.
- No hidden synthetic identity.
- No sexualized minor-like appearance.
- No adult-content policy evasion language.

## Default Direction

Prefer stylized, brand-safe, consistent synthetic identity. Make the creator
clearly disclosed as AI-generated when required or when the content could
reasonably mislead viewers.
