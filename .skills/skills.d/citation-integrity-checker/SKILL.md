# citation-integrity-checker

Use this skill to verify citation integrity in legal documents. Every cite should trace to a real source with correct page numbers and accurate quotations.

## Rules

- Every citation must have a source document or authority.
- Check pinpoint page numbers against the actual source.
- Verify quoted text matches the source verbatim.
- Flag citations with no traceable source as UNVERIFIED.
- Flag paraphrased content presented as direct quotes.
- Report Shepard/KeyCite status if available, but never fabricate it.

## Outputs

- citation audit table
- verified citations list
- unverified citations list
- misquoted text flagger
- pinpoint page error report
- source index
