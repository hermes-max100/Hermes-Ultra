# agentic-coding-router

Use this skill when a coding task needs routing to the right execution pattern: script generation, repo analysis, build, test, or full agentic build.

## Rules

- Identify the task type first: script, refactor, build, test, deploy.
- Select the minimal sufficient toolchain.
- Do not run destructive commands without explicit confirmation.
- Log all file changes.
- Run tests after code modification.

## Outputs

- execution plan
- generated code
- test results
- build log
- deployment status
